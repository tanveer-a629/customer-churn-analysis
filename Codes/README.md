# Customer Churn Analysis – Code Files

This folder contains the SQL, Python, Power Query, and DAX files used in the Customer Churn Analysis project.

## Files

- `SQL_Queries.sql` – SQL queries for data exploration, validation, transformation, and views.
- `churn_prediction_model.py` – Random Forest model training and evaluation.
- `predict_churn.py` – Loads the trained model and predicts high-risk churn customers.
- `Power_Query_Transformations.txt` – Power Query transformations used for data preparation.
- `DAX_Measures_Combined.txt` – Power BI DAX measures used in the dashboard.

## Tools Used

SQL Server · Python · Power BI · Power Query · DAX · Random Forest
